# Flujo de trabajo diario

1. Elegir una tarea pequeña ligada a un requisito.
2. Leer documentación y decisiones relacionadas.
3. Definir resultado esperado y criterios de aceptación.
4. Diseñar primero si afecta datos, permisos o arquitectura.
5. Implementar un cambio aislado.
6. Ejecutar pruebas y revisar manualmente.
7. Actualizar documentación afectada.
8. Marcar estado: terminado, probado, bloqueado o pendiente.
9. Hacer un commit descriptivo cuando esté verificado.
10. Elegir la siguiente tarea prioritaria.

No trabajar directamente en producción ni subir secretos o datos reales al repositorio.
