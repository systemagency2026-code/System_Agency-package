# Hoja de ruta

## Fase 0 — Descubrimiento
Confirmar proceso real, roles, MVP, presupuesto y criterios de aceptación.

## Fase 1 — Diseño
Aprobar arquitectura, modelo de datos, permisos y decisiones técnicas.

## Fase 2 — Entorno
Configurar VS Code, Git, Supabase local/entorno de pruebas y variables.

## Fase 3 — Base de datos
Crear migraciones aprobadas, restricciones, índices, RLS y pruebas SQL.

## Fase 4 — Interfaz
Desarrollar navegación, formularios y listados por módulo con datos ficticios.

## Fase 5 — Integración y QA
Conectar servicios, probar flujos, permisos y acceso cruzado entre agencias.

## Fase 6 — Entrega
Desplegar, verificar respaldos, capacitar usuarios y documentar limitaciones.

No pasar a producción sin pruebas de aislamiento entre agencias.
