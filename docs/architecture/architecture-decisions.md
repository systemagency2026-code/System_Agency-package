# Registro de decisiones de arquitectura (ADR)

## ADR-001 — Workspace modular
- Estado: aceptada como estructura inicial.
- Decisión: separar documentación, frontend, base de datos y API opcional.
- Consecuencia: la interfaz puede revisarse antes de conectar datos.

## ADR-002 — Supabase
- Estado: propuesta pendiente.
- Opciones: Supabase como backend principal o una API independiente.
- Pendiente: validar autenticación, RLS, permisos, operaciones y presupuesto.
